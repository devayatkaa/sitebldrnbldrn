# Проверка адаптивности

Первый запуск:

```sh
npm install
npx playwright install chromium
npm run test:responsive
```

Команда собирает production-версию, запускает отдельный сервер на порту 3100
и проверяет Chromium на размерах 320×568, 360×800, 375×812, 390×844,
393×873, 412×915, 430×932, их горизонтальных вариантах, 768×1024
и 1440×900. Отдельный профиль 393×873 использует DPR 3, остальные — DPR 1.
Порт 3100 должен быть свободен.

Проверки ловят выход текста за границы, пересечения названий и просмотров,
сжатие изображения Hero, перекрытие подписи кнопками, выезд меню за экран,
исчезновение кнопок после нажатий, проблемы фильтров и поворота экрана.
Отдельный сценарий проверяет настоящие анимации без reduced-motion.
Дополнительно проверяются поворот туда и обратно, уменьшение доступной высоты,
увеличение текста описания, пропорции кота и неподвижность EDIT при его парении. Эталонные скриншоты
ПК в `desktop.spec.ts-snapshots` защищают одобренный дизайн Hero и AboutMe.
Не обновляйте эти эталоны при исправлениях мобильной версии.

Скриншоты Hero и AboutMe сохраняются в `test-results`, ошибки — вместе с trace.
Отчёт: `npm run test:responsive:report`.

Нужен доступ к хранилищу R2 для реальных изображений. Медиа не подменяются.
Эмуляция не заменяет проверку скорости видео на физическом Android.
На низком горизонтальном экране Hero намеренно прокручивается, а не сжимает
кота и текст до нечитаемых размеров. Стили для телефонов находятся в
`src/app/globals.css`, блок `Phone layout`.

Мобильная шапка находится в потоке. Отдельный `MobileHero.tsx` использует grid;
`.mobile-hero-visual` задаёт единый масштаб заголовка, EDIT и кота в `cqw`.
EDIT — независимый декоративный слой с естественными пропорциями букв,
который заходит под заголовок и продолжается за котом. Его края намеренно
обрезаются границами hero, а не внутренними отступами композиции.
Тест проверяет пересечение слоёв, их порядок и отсутствие переполнения страницы.
В landscape уменьшается ширина всей композиции, сохраняя пропорции элементов.
CSS переключает desktop/mobile на 1024 px без ветвления JSX по размеру окна.
Desktop-разметка и её стили остаются независимыми от `MobileHero`.

Существующая команда `npm run lint` вызывает удалённый в Next 16 `next lint`.
ESLint в проекте не установлен; сборка проверяет TypeScript, отдельно доступен
`npx tsc --noEmit`. Не считать ошибку запуска старой команды успешным lint.
